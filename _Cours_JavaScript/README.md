# Cours JavaScript : chapitres, exemples et exercices

Ce dossier reprend le contenu de `JsFolderDemo` corrigé et complété. Les fichiers d'origine ne sont pas modifiés.

## Comment l'utiliser
1. Lire `exemple.js` du chapitre et l'exécuter.
2. Faire les exercices de `exercices.md`, du niveau 1 au niveau 3.
3. Comparer avec les corrections en bas du fichier `exercices.md`.

- **Chapitres sans DOM** (01, 02, 04 à 16, 19) : `node exemple.js` dans le terminal, ou la console du navigateur.
- **Chapitres avec DOM** (03, 17, 18, 20, 99) : ouvrir `index.html` dans le navigateur. La console (F12) affiche les résultats.
- Les chapitres 18 et 20 utilisent du réseau : la page doit être servie (`python -m http.server`) pour le fichier JSON.
